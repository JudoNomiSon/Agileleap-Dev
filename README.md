# AgileLeap.AI Website

Updated homepage for agileleap.ai — built with React/Next.js.

## New Features
- 3D audience segment buttons (Vibe Coders, SMB, Federal & GovCon)
- Sherpa mascot character integration
- Scroll-triggered animations and stat counters
- Refreshed dark navy design system

## Project Structure
```
src/
  components/
    AgileLeapHomepage.jsx
public/
  images/
    sherpa-thumbsup.png
    sherpa-avatar.png
```

## Setup
Drop AgileLeapHomepage.jsx into your existing Next.js project components directory and import it as your homepage.
